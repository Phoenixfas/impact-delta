## Architecture

Single-page marketing site (App Router, `app/` directory) for "IMPACT B2B", a corporate event/summit platform. Everything currently renders through one route: `app/page.tsx`.

- **`app/layout.tsx`** — root layout. Loads Geist fonts, sets global metadata, and wraps all content in two always-mounted providers: `KineticBackground` (visual layer) and `SmoothScroll` (scroll behavior). Both are client components and both matter for anything rendered on the page.
- **`components/SmoothScroll.tsx`** — wraps the app in a Lenis smooth-scroll instance synced to GSAP's ticker/`ScrollTrigger` (so Lenis drives the scroll position and GSAP scroll-triggered animations stay in lockstep). Exposes `useSmoothScroll()` (context hook) giving `{ lenis, scrollTo }` — use `scrollTo` instead of `window.scrollTo`/`scrollIntoView` for any in-page navigation so it respects the smooth-scroll physics.
- **`components/KineticBackground.tsx`** — fixed, `-z-10`, `pointer-events-none` canvas covering the viewport. Runs its own rAF loop (independent of GSAP/Lenis) rendering ambient gradient blobs, a pointer-reactive particle lattice, and floating dust, plus a static noise/vignette overlay. Pure canvas 2D, no external animation lib.
- **`app/page.tsx`** — the homepage. Client component; wires up GSAP `ScrollTrigger` reveal animations (hero stagger, bento grid, metrics, timeline) inside a `gsap.context()` for scoped cleanup, plus a pointer-speed telemetry readout. Section animations key off CSS classes (`.hero-badge`, `.bento-item`, `.metric-card`, `.timeline-step`, etc.) rather than refs — new sections that want scroll-triggered reveals should follow the same class-hook convention and register inside the existing `gsap.context()`.

## Styling

Tailwind CSS v4 (via `@tailwindcss/postcss`, no `tailwind.config.*` — config lives in `app/globals.css` using `@import "tailwindcss"` + `:root` custom properties). The brand palette, gradient, border, and diffused-shadow tokens are all defined there — reuse those CSS variables (`--primary`, `--secondary`, `--tertiary`, `--shadow-diffused-*`, `--gradient-corporate`, etc.) rather than hardcoding new colors/shadows.

Icons: `lucide-react`. Animation: `gsap` (with `ScrollTrigger`) for scroll/reveal choreography, `lenis` for scroll physics — both are already initialized globally, don't re-instantiate per component.
