## Architecture

Single-page marketing site (App Router, `app/` directory) for "IMPACT B2B", a corporate event/summit platform. Everything renders through one route: `app/page.tsx`, composed from section components in `components/`.

- **`app/layout.tsx`** — root layout. Loads Geist fonts, sets global metadata, and wraps all content in two always-mounted providers: `KineticBackground` (visual layer) and `SmoothScroll` (scroll behavior). Both are client components and both matter for anything rendered on the page.
- **`components/SmoothScroll.tsx`** — wraps the app in a Lenis smooth-scroll instance synced to GSAP's ticker/`ScrollTrigger` (so Lenis drives the scroll position and GSAP scroll-triggered animations stay in lockstep). Exposes `useSmoothScroll()` (context hook) giving `{ lenis, scrollTo }` — use `scrollTo` instead of `window.scrollTo`/`scrollIntoView` for any in-page navigation (including anchor links) so it respects the smooth-scroll physics and header offset.
- **`components/KineticBackground.tsx`** — fixed, `-z-10`, `pointer-events-none` canvas covering the viewport, mounted once in the root layout. Runs its own rAF loop (independent of GSAP/Lenis) rendering ambient gradient blobs, a pointer-reactive particle lattice, and floating dust, plus a static noise/vignette overlay. Pure canvas 2D, no external animation lib.
- **`components/Navbar.tsx`** — fixed pill-shaped header. Nav items are hash links (`#hero`, `#portfolio`, `#solutions`, `#stage`, `#about`, `#contact`) resolved by `scrollTo` from `SmoothScroll`; the target `id`s live on sections in `HeroSection`/`page.tsx`, so renaming a section's `id` means updating `NAV_ITEMS` here too.
- **`components/HeroSection.tsx`** — the `#hero` section. Orchestrates its own GSAP entrance timeline, gated behind `ParticleRevealMask`'s `onRevealComplete` callback (nothing in the hero animates in until the particle-burst intro finishes), plus scroll-scrubbed parallax (`.hero-parallax-bg`, headline, constellation wrapper) via a separate `ScrollTrigger`. Contains `HeroConstellation` (the `#stage` 3D-tilt showcase panels) and `ParticleRevealMask` (canvas particle-burst intro) as `components/hero/` subcomponents.
- **`app/page.tsx`** — renders `Navbar` + `HeroSection`, then the `#portfolio` (bento grid), `#solutions`, and `#contact` sections plus the footer. Wires up its own GSAP `ScrollTrigger` reveal animations (bento grid, solution cards, metrics) inside a `gsap.context()` for scoped cleanup. Section animations key off CSS classes (`.bento-item`, `.solution-card`, `.metric-card`, etc.) rather than refs — new sections that want scroll-triggered reveals should follow the same class-hook convention and register inside the existing `gsap.context()`.

Each section component that runs GSAP owns its own `gsap.registerPlugin(ScrollTrigger)` + `gsap.context()`/`ctx.revert()` pair — this is the established pattern for new animated sections, not a single shared timeline.

## Styling

Tailwind CSS v4 (via `@tailwindcss/postcss`, no `tailwind.config.*` — config lives in `app/globals.css` using `@import "tailwindcss"` + `:root` custom properties). The brand palette, gradient, border, and diffused-shadow tokens are all defined there — reuse those CSS variables (`--primary`, `--secondary`, `--tertiary`, `--shadow-diffused-*`, `--gradient-corporate`, etc.) rather than hardcoding new colors/shadows.

Icons: `lucide-react`. Animation: `gsap` (with `ScrollTrigger`) for scroll/reveal choreography, `lenis` for scroll physics — both are already initialized globally, don't re-instantiate per component.
